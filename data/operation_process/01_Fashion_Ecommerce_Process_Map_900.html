7 CORE DOMAINS | Front ⇄ Admin 양방향 데이터 연계 허브 노드


[전시] Display Hub

Admin 설정 ➔ Front 노출

· CategoryTree (카테고리 트리)

· DisplaySlot (홈/피드 구좌)

· RankingScore (실시간 랭킹)


[기획전] Promo Hub

Admin 편성 ➔ Front 발행

· CampaignMaster (기획전 마스터)

· CouponRule (쿠폰/할인율 룰)

· TimeDealSchedule (특가 일정)


[상품] Product / PIM

Admin 승인 ➔ 실시간 ATP

· FashionPIM (스타일-컬러-사이즈)

· RealtimeATP (통합 가용재고)

· PricePolicy (정상/할인/임직원가)


[회원] Member / CRM

Front 인증 ⇄ Admin 혜택

· MemberProfile (체형/스타일)

· LoyaltyTier (VIP 멤버십 등급)

· PointWallet (패션 마일리지)


[주문] Order / OMS

Front 결제 ➔ Admin OMS

· OrderMaster (주문서 헤더/라인)

· PaymentRecord (복합결제 대사)

· SplitOrder (출하지별 주문분할)


[배송] Logistics / WMS

Admin 출고 ➔ Front 추적

· FulfillmentOrder (피킹/패킹 지시)

· WaybillCarrier (택배사 송장 EDI)

· TrackingCheckpoint (위치상태)


[클레임] Claim / RMA

Front 접수 ➔ Admin 검수

· ClaimRequest (반품/교환 접수)

· QCInspection (물류 입고 검수)

· RefundLedger (환불/정산 차감)

홈/피드 노출 스케줄링

③ 랭킹 가중치 설정
판매/클릭/찜 스코어링

➔ Front 홈 실시간 배포

시작/종료 스케줄러 구동

➔ 쿠폰 실시간 발급 개시

③ 안전재고 임계치 제어
자동 품절 처리 기준 설정

➔ 실시간 판매 상태 제어


회원 등급·CRM 룰

② 마일리지 수동 승인

➔ 고객 지갑 실시간 갱신

CROSS-DOMAIN SYNERGY | 글로벌 3대 유기적 연계 프로세스 루프 (Closed-Loop)


1. 주문-재고 실시간 오케스트레이션 루프 (EDA Loop)

① 주문결제
OrderPaid

② ATP 차감
가용재고 동기화

③ 출하지시
WMS 릴리즈

④ 랭킹점수 반영
전시 랭킹 즉시 갱신

· 결제 즉시 마일리지/쿠폰 소멸 및 상품 ATP 차감 ➔ 안전재고 도달 시 자동 품절 반영


2. 옴니채널 재고 통합 라우팅 루프 (Omni Logistics Loop)

① 주문 인입
배송지 분석

② 거점 할당
물류센터/매장

③ 송장 채번
택배 EDI 연동

④ 실시간 트래킹
배송출발 알림톡

· 센터 재고 결품 시 인근 오프라인 매장 재고로 자동 대체 출고 라우팅 (Farfetch/Zalando 표준)


3. 무마찰 리버스 로지스틱스 루프 (Reverse RMA Loop)

① 반품신청
고객 원터치

② 회수 채번
택배사 수거지시

③ 바코드 QC
물류센터 양품판정

④ 즉시 환불승인
배송비 차감 자동환불

· 입고 검수 즉시 반품배송비 자동 차감 후 30초 내 즉시 계좌/카드 환불 (맞교환 시 자동 재출고)
