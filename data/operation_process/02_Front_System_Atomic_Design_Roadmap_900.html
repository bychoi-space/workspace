디자인 가이드 부재 ➔ Atomic SSOT 정립

Storybook 컴포넌트 주도 개발(CDD)


1. REASON & TRANSFORMATION STRATEGY


AS-IS (현재 문제)

디자인 스타일 가이드 부재

• 화면별 UI 스타일 파편화

• 컴포넌트 중복 코딩 발생

• 릴리즈마다 디자인 불일치


TO-BE (개편 전략)

Atomic Design & Storybook

• 시선 전사 단일 디자인 SSOT

• 스토리북 기반 컴포넌트 자산화

• Front 전 화면 표준 UI 개편


2. ATOMIC PATTERN DESIGN 5-STEP HIERARCHY & STORYBOOK

원자에서 페이지까지 체계적 컴포넌트 빌드


1. Atoms (원자)

최소 단위 기초 자산

• Color: 시선 전용 팔레트

• Typography: 13~24px 스케일

• Icon: .lf-icon SVG 아톰

• Button, Input, Checkbox


2. Molecules (분자)

단순 기능 복합 컴포넌트

• 검색바 (인풋 + 검색버튼)

• 수량 카운터 (+ / - 조절)

• 상품 상태 태그 & 할인율 뱃지

• 드롭다운 옵션 셀렉터


3. Organisms (유기체)

독립적 UI 인터페이스

• GNB 통합 헤더 & LNB

• 상품 카드 (사진+가격+리뷰)

• 카테고리 필터 바 (다중속성)

• 주문서 결제 수단 선택 블록


4. Templates (템플릿)

데이터 없는 화면 구조

• 메인 쇼케이스 3단 레이아웃

• PLP 4열 반응형 상품 그리드

• PDP 좌/우 2컬럼 상세 구조

• 마이페이지 사이드바+본문


5. Storybook Hub

라이브 가이드 & 배포

• 컴포넌트 독립 라이브 프리뷰

• 상태(Props/State)별 자동 문서

• UI 인터랙션 회귀 테스트

• Front 화면별 컴포넌트 배포


3. FRONT SYSTEM SCREEN-BY-SCREEN UI ROLLOUT ROADMAP (우선순위 & 페이지 중요도 기반)

첫번째 스크린의 모든 Front 화면(통합메인~마이페이지)을 CVR & 중요도 순으로 4단계 개편


Phase 1. Wave 1 (최우선 / Critical)

매출 & CVR 직결

브랜드 첫인상 정립 & 결제 이탈 최소화 (핵심 4대 화면)


통합 메인

3대 브랜드

통합 메인 & 브랜드 메인

• GNB/LNB 헤더 공통 모듈화

• MICHAA, IT MICHAA, EBM 일관화

• 히어로 롤링 배너 Organism 구축


상품 상세

주문서

Phase 2. Wave 2 (고우선 / High)

탐색 & 전환 가속
