상품관리

AS-IS

카테고리 파편화 및 이원화 ﻿: 브랜드별로 카테고리 체계가 다르고, PC와 Mobile을 따로 등록/관리하여 운영 공수 급증﻿

단순 전시 기능의 한계 : 영역별 이미지, 상품, 배너, 팝업 등 기초적 요소만 수동 등록하는 제한적 구조﻿

AS-IS

수작업 입력 의존 : ERP 로부터 최소한의 데이터만 전송 받아 생성 후, 온라인MD가 직접 상품 정보를 일일이 채워넣는 형태로만 운영﻿

빈약한 사이즈 조견표 : 상품의 총길이, 가슴단면 등 단순 치수 정보만 표기되어 고객 맞춤형 안내 부재﻿﻿

AS-IS

단순 배송 조회에 국한 : 현재 시스템은 단순하게 택배 송장을 조회하고, ERP에 매출을 반영하는 기능만 한정적으로 존재﻿

도착 시점 예측 정보 부재 : 실시간 재고와 출고 리드타임이 연계되지 않아 실제 배송 도착 시점 안내 불가﻿

① 구조적 카테고리 통합 (공통 규격)

브랜드와 디바이스(PC/Mobile)에 구애받지 않고 유기적으로 연결되는 공통 카테고리 구조를 전면 수립하여 단일 SSOT로 관리

② 브랜드별 스페셜 카테고리 분리

각 브랜드 고유의 콘셉트와 특성을 반영해야 하는 스페셜 카테고리는 별도 전용 기능으로 정밀 분리하여 유연성 극대화

 Front의 모든 영역을 모듈형 [카드 블록]으로 표준화하고, 어드민에서 카드를 자유롭게 세팅하면 실시간 자동 퍼블리싱되는 구조적 아키텍처 완성

③ Front 전 화면 카드화 & 자동 조립

① LLM 기반 상세 정보 자동 보강

상품 상세 정보에 데이터 기반 LLM을 구성하여, 최소 ERP 데이터로부터 상세 스펙과 특장점을 자동으로 추론 및 보강하는 자동 생성 체계 구축

② TPO별 추천 키워드 분류 & 연동

상품 데이터를 기반으로 TPO(Time·Place·Occasion) 맞춤 추천 키워드를 체계적으로 분류하고, 이를 FRONT 화면에 동적으로 연동 출력

단순 단면 치수를 넘어 소비자의 키와 체중에 대한 스펙 데이터를 체계화하여, 개별 체형에 가장 적합한 사이즈를 정밀 제안하는 기능 구현

③ 키·체중 체형 맞춤 사이즈 제안

① 물류센터 실시간 재고 연동 조회

물류센터 현장 재고를 실시간으로 직접 조회하고, 물류 거점별 출고 가능 수량을 즉각 산출하는 기반 연동망 구축

② 출고-배송 도착 시점 시뮬레이션

조회된 재고를 기반으로 주문 후 물류센터 출고 시점과 고객 배송 완료 시점을 정밀하게 시뮬레이션하여 데이터화

'배송예정일 자동화' 신규 프로젝트를 도입하여, 고객이 결제 전/주문서/상세페이지에서 언제쯤 도착 예정인지 명확히 확인하도록 구현

③ [배송예정일 자동화] 프로젝트 추진
