OBJECTIVE

• 시선닷컴 상품 상세 페이지 (PDP) 리뉴얼 누락부분 개선

(1) 컬러칩 텍스트 직관적으로 표현
클릭 전에도 색상명을 즉시 인지 가능하도록 UI 개선
(2) 오프라인 매장 찾기 기능 추가
상품 보유 및 인근 오프라인 매장 위치 안내 동선 도입
(3) 상품정보 확인 버튼 버튼 추가
필수 고시정보 및 상품 스펙을 즉시 조회하는 퀵 버튼 제공


📋 2. 과제 작업 범위

SCOPE

📱 Front UI 개발 IN SCOPE

기획 · 디자인 · 퍼블리싱 · 개발

• 기획: 요구사항 정의 및 화면설계서(SB)

• 디자인: PC & Mobile UI/GUI 가이드

• 퍼블리싱: 반응형 웹 마크업 구현

• 개발: 프론트엔드 연동 및 UI 기능 개발

⚙️ Admin 백오피스 OUT OF SCOPE

🚫 Admin 개발 없음

• 기존 어드민 인프라 및 API 100% 활용

• 별도 관리자 신규 화면/메뉴 개발 제외

• 백엔드 DB 스키마 변경 사항 없음

• Front 전담 집중으로 개발 일정 단축
