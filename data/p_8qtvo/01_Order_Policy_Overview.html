ORDER POLICY SPEC · v1.0
STAGE 01 · CART

1. 장바구니 정책

일반 장바구니
포인트몰 기준
상품 개수

최대 100개까지 저장 가능  (단품 색상 · 사이즈 옵션 단위로 개별 구분하여 카운트)

보관 기한

30일 유지 / 이후 자동 삭제  (장바구니에 등록된 시점부터 30일간 자동 보관 후 만료분 일괄 삭제)

회원 여부

비회원(로그아웃) 상태에서도 장바구니 담기 가능 / 세션 유지 상태에서 로그인 시 회원 장바구니에 연동 · 취합 보관  (※ 포인트몰은 로그인 회원만 가능)

수량 제한 · 수정

상품 재고 기준 주문가능 수량까지 추가 가능  (수량 · 색상 · 사이즈 변경 가능 / 담겨있던 상품을 주문 · 결제 완료할 경우 자동 삭제)

STAGE 02 · ORDER

2. 주문서 정책

할인 적용 순위
배송지 · 배송비
상품 확인

주문 대상 상품의 상품 이미지, 상품명, TAG가격, 옵션, 수량 표시  (* 주문서 내에서는 옵션 및 수량 수정 불가)

할인 적용 순위

1순위 프로모션(시스템 자동) ➔ 2순위 상품쿠폰 ➔ 3순위 포인트 ➔ 4순위 스페셜쿠폰(상품쿠폰 중복불가) ➔ 5순위 장바구니쿠폰

주문자 · 배송정보

회원 주문 : 저장된 DB 배송지 자동 입력  /  비회원 주문 : 주문자 · 연락처 · 정보수집 동의 체크 영역 생성 및 배송지 공란(직접 입력)

배송비 기준

기본 배송비 2,500원 / 5만원 이상 구매 시 무료배송  (* 배송비 무료 쿠폰은 별도 할인 / 무료배송 주문의 경우 사용 불가)

STAGE 03 · PAYMENT

3. 결제 · 완료 정책

KG이니시스 연동
수수료 · 쿠폰 제한
결제 수단

신용카드 / 실시간 계좌이체 / 가상계좌 입금 중 선택  (* 결제 모듈 'KG이니시스' 플러그인 호출 연동)

결제 수수료

신용카드 : 결제비용의 2.55%(VAT별도)  /  계좌이체 : 결제비용의 1.50%(최저수수료 200원, VAT별도)  /  가상계좌 : 건당 200원(VAT별도)

쿠폰 발급 제한

상품쿠폰 중 [다운로드 쿠폰]은 사전 다운받은 고객만 사용 가능  (* 해당하는 상품상세페이지에서 고객 직접 다운로드 저장 가능)

주문 확정 · 취소

결제 승인 시 실물 재고 차감 및 장바구니 주문 상품 자동 삭제  (가상계좌 미입금 자동 취소 또는 전체 취소 시 점유 재고 · 쿠폰 · 포인트 즉시 복원)
