1. 장바구니 정책

상품 개수 · 보관 기한

설정 기능

상품 개수

최대 100개까지 저장 가능  (단품 색상 · 사이즈 옵션 단위로 개별 구분하여 카운트)

보관 기한

30일 유지 / 이후 자동 삭제  (장바구니에 등록된 시점부터 30일간 자동 보관 후 만료분 일괄 삭제)

회원 여부

비회원(로그아웃) 상태에서도 장바구니 담기 가능 / 세션 유지 상태에서 로그인 시 회원 장바구니에 연동 · 취합 보관

수량 제한 · 수정

상품 재고 기준 주문가능 수량까지 추가 가능  (수량 · 색상 · 사이즈 변경 가능 / 담겨있던 상품을 주문 · 결제 완료할 경우 자동 삭제)

고객 수동 쿠폰 적용 (자동적용 지양) 우선순위 없음 / 중복 할인 : 상품쿠폰 + 장바구니쿠폰 이중 적용 가능 (상품쿠폰 선 할인 계산 후, 장바구티 쿠폰 할인)

주문자 · 배송정보

회원 주문만 가능 / 비회원 주문 불가 (악용하는 악성 고객에 대한 리스크 고려)

배송비 기준

기본 배송비 모든 상품 무료배송

3. 결제 · 완료 정책

결제 PG 연동

수수료 · 쿠폰 제한

결제 수단

토스페이 / 카카오페이 / 네이버페이 / 페이코 / 신용카드 / 무통장입금 / 실시간 계좌이체 (결제 모듈 'KOREA PAYMENT NETWORKS' 플러그인 호출 연동)

결제 수수료

신용카드 : 결제비용의 2.55%(VAT별도)  /  계좌이체 : 결제비용의 1.50%(최저수수료 200원, VAT별도)  /  가상계좌 : 건당 200원(VAT별도)

적립 마일리지

적립 마일리지는 [구매 후 적립금으로 받기] 와 [즉시 할인 받기] 로 고객 선택적 활용 가능  (일부 특가 쿠폰이 적용 된 경우 적립 마일리지 제공하지 않음)

주문 확정 · 취소

결제 승인 시 실물 재고 차감 및 장바구니 주문 상품 자동 삭제  (가상계좌 미입금 자동 취소 또는 전체 취소 시 점유 재고 · 쿠폰 · 포인트 즉시 복원)
