01. 장바구니

상품 보관 · 비로그인 · 추천 정책


① 보관 수량·기간

최대 100개 보관 · 30일 후 자동 삭제

계정당 최대 [ 100개 ] 품목 보관 | 담은 날로부터 [ 30일간 ] 보관

• 수량 초과 안내 : 100개 초과 담기 시 최대 보관 한도 얼럿 노출

• 자동 삭제 배치 : 30일 경과 상품 자동 삭제 (하단 유의사항 상시 명시)

• 품절 상품 관리 : 품절 시 선택 체크박스 비활성화 및 [품절상품 삭제] 지원


② 비로그인 정책

세션 장바구니 노출 & 로그인 자동 병합

비로그인 세션 담기 지원 ➔ 로그인 시 회원 장바구니 자동 병합

• Empty 화면 구성 : 담긴 상품 없을 시 안내 문구 및 [로그인] 유도 버튼 노출

• 로그인 시 병합 : 비로그인 담기 상품을 회원 장바구니에 병합 (동일옵션 합산)

• 주문 진입 제어 : 비로그인 상태에서 [결제] 클릭 시 로그인 페이지로 이동


③ 추천 상품 로직

'장바구니에 많이 담긴 상품 추천' 큐레이션

최근 7일간 시선닷컴 전체 고객 '장바구니 담기' 누적 상위 상품

• 상시 노출 원칙 : 장바구니 담긴 상품 유무와 무관하게 하단 상시 노출

• 제외 필터링 : 내 장바구니에 이미 담긴 상품 및 품절/판매종료 상품 제외

• 캐러셀 UI : 썸네일 · 마케팅워드 · 브랜드 · 상품명 · 할인가 · 컬러칩


02. 주문서

동시 주문 한도 · 배송지 3대 케이스 정책


① 주문 상품·한도

최대 50개 동시 결제 & 주문 상품 리스트

1회 주문서당 최대 [ 50개 ] 품목 동시 결제 | 우측 상단 '총 N개' 표시

• 단품 수량 기준 : 옵션당 최대 구매 수량은 실재고 및 브랜드별 제한 기준 적용

• 테이블 컬럼 : 상품정보 · 수량 · 마일리지 · 쿠폰 · 장바구니쿠폰 · 주문금액

• 변경 제한 원칙 : 주문서 내 옵션/수량 직접 변경 불가 (장바구니에서 변경)


② 배송지 3대 케이스

기본 배송지 · 신규 입력 · 주소록 팝업

[기본 배송지] 탭 기본 활성화 | 미존재 시 [새로운 배송지] 자동 전환

• Case 1 (기본 존재) : 저장된 수령인·우편번호·주소·연락처 즉시 바인딩

• Case 2 (최초/미존재) : 신규 입력 폼 노출 및 결제 시 기본배송지 자동 등록

• Case 3 (변경/추가) : [새로운 배송지] 입력 및 [배송지 목록 〉] 팝업 호출


③ 배송 유의사항

배송기사 전달 메시지 & 직접입력 연동

배송요청 프리셋 드롭다운 기본 제공 + [직접입력] 체크박스 연동

• 기본 플레이스홀더 : "배송기사님에게 전달되는 메세지 입니다. 선택해주세요."

• 프리셋 옵션 : 문앞에 놓아주세요 / 경비실 보관 / 택배함 보관 등 제공

• 직접입력 연동 : 우측 상단 [직접입력] 체크 시 하단 상세 입력창 노출


03. 혜택·결제

쿠폰·마일리지 · 결제수단 · 완료 정책


① 쿠폰·마일리지

최초 '미적용' 원칙 & 최대 혜택 자동계산

최초 진입 시 '쿠폰 미적용(0원)' ➔ [최대 혜택] 체크 시 자동 계산

• 할인 수단 체계 : 상품 쿠폰(단품별) + 장바구니 쿠폰(주문전체) + 마일리지

• 수동 변경 연동 : [쿠폰 변경] 팝업에서 직접 수정 시 [최대 혜택] 체크 해제

• 마일리지 차감 : 보유 마일리지 내 [모두사용] 원클릭 전액 적용 지원


② 결제수단 (7종)

간편결제 4종 · 일반결제 3종 구성

최초 진입 기본 선택값 : [ 신용카드 ] | 최근 결제수단 자동 유지

• 간편결제 (4종) : 토스페이 · 카카오페이 · 네이버페이 · 페이코

• 일반결제 (3종) : 신용카드 · 무통장입금(가상계좌) · 실시간 계좌이체

• 결제 혜택 안내 : 카드사별 무이자 할부 및 간편결제 프로모션 안내 연동


③ 주문완료·취소

주문완료 요약 노출 & 전체취소 원칙

결제 후 옵션/수량 변경 및 부분취소 불가 (전체 취소 후 재주문)

• 주문번호 채번 : PG 승인 즉시 주문번호 발급 및 알림톡/이메일 발송

• 완료 화면 요약 : 총 상품금액·배송비·할인내역·최종결제액 및 배송지 노출

• 사전 고지 의무 : 주문서 하단 약관 영역에 '부분취소 불가' 유의사항 명시
