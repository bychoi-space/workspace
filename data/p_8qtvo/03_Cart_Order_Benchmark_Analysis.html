UX/UI BENCHMARK


1. 시선닷컴 PC / Mobile 실물 화면 정밀 분석 (4대 도메인 캡처)


[PC] 장바구니

정형화된 6단 테이블

• 브랜드별 소계/배송비 분리 없는 단일 플랫 리스트 구조

• 쿠폰 사전 적용 불가 (주문서 진입 후에야 최종가 확인)

• 수량 인라인 수정 불가 (옵션변경 팝업 별도 진입 필요)


[MO] 장바구니

하단 플로팅 바 부재

• Sticky 주문 바가 없어 상품 5개 이상 시 최하단까지 장문 스크롤 필요

• 실시간 합산 금액 및 구매 CTA 접근성 저하로 장바구니 이탈 발생

• 품절 임박/재고 긴급성(FOMO) 알림 뱃지 결여


[PC] 주문서

할인 입력 단계 분절

• 쿠폰선택 + 마일리지입력 + 선할인 라디오 등 4단계 수동 분리

• '최대 할인 자동 적용' 기능 부재로 고객의 최적가 탐색 피로 발생

• 결제 약관 별도 체크박스 체크 요구로 클릭 뎁스 증가


[MO] 주문서

상단 유의사항 과노출

• 최상단 장문 유의사항(6줄)이 기본 펼쳐져 뷰포트 절반 잠식

• 간편결제(네이버/카카오/토스)가 일반 라디오 리스트로 평이하게 나열

• 배송지 변경 시 화면 이탈 없는 바텀시트 퀵 변경 UX 미흡

3. 단계별 UX/UI 고도화 실행 로드맵 (Quick Win ➔ Core Conversion ➔ Brand Synergy)


PHASE 1 (1~2주)

Quick Wins (즉시 이탈 방어)

• 모바일 장바구니 하단 Sticky 주문 바 신설 (구매 버튼 상시 노출)

• 모바일 주문서 상단 장문 유의사항 기본 축소 (첫 뷰포트 확보)

• [동의하고 결제하기] 단일 통합 버튼 (불필요한 체크 클릭 제거)


PHASE 2 (3~4주)

Core Conversion (결제 전환율 극대화)

• 원클릭 [최대 할인 자동 적용] 엔진 (쿠폰+마일리지 최적가 세팅)

• 간편결제(네이버/카카오/토스) 상단 퀵 타일 그리드 전진 배치

• 장바구니 단계 최대 혜택가 사전 시뮬레이션 및 즉시 체감가 노출


PHASE 3 (5~6주)

Brand Synergy (브랜드 자사몰 고도화)

• 브랜드별 묶음 배송 & 무료배송 충족 게이지 ("00원 더 담으면 무료")

• 인라인 수량 조절 Stepper UI 및 품절 임박 뱃지(FOMO 넛지) 도입

• 바텀시트(Bottom Sheet) 배송지 퀵 변경 및 원페이지 체크아웃 완성
