기획전 템플릿화 과제 개요 (Project Summary)


과제 목적

OBJECTIVE


• 기획전 템플릿화 구축을 통한 운영 공수 절감 및 실시간 마케팅 대응 체계 확립


(1) 운영 효율성

운영 효율성 증대

반복 제작 공수를 제거하여 기획전 런칭/운영 리소스 대폭 절감


(2) 즉각적 대응

컨틴전시 대응

긴급/컨틴전시 기획전 발생 시 템플릿 기반 즉각적인 프로모션 론칭


(3) 셀프 서비스

온라인MD 즉시 반영

개발·디자인 지원 없이 온라인MD가 어드민에서 기획전 내용 직접 수정


작업 범위

SCOPE


Front UI 구축

IN SCOPE

기획 · 디자인 · 퍼블리싱 · 개발

• 기획 : 반응형 템플릿 요구정의 및 화면설계(SB)

• 디자인 : PC & Mobile UI/UX 디자인 가이드

• 퍼블리싱 : 반응형 웹 마크업 및 인터랙션 구현

• 개발 : 프론트 템플릿 컴포넌트 렌더링 개발


Admin & 랭킹 엔진

IN SCOPE

기획 · 개발 + 상품 랭킹 룰 & Batch

• Admin 기획 : 기획전 등록·관리 및 랭킹 설정 UI

• Admin 개발 : 기획전 CMS 관리 및 데이터/API 연동

• 상품 랭킹 룰 : 진열 순서 규정 알고리즘 및 룰 수립

• Batch 개발 : 랭킹 점수 산정 및 주기적 자동 정렬 배치
