[회원] 악성 고객 주문 제한 조치 과제 개요 (Project Summary)

SISUN.COM E-COMMERCE

VERSION 0.1


1. 과제 목적 및 추진 배경

OBJECTIVE


• 과다 반품(반품율 90% 이상) 악성 고객의 주문을 사전 통제하여 물류 리소스 낭비 방지 및 재고 회전율 정상화


(1) 물류 비용 절감

출고·반품 비용 차단

과다 반품 고객의 반복 출고 및 반품 회수 물류 업무 리소스 소모와 왕복 택배 비용 누수를 원천 차단합니다.


(2) 재고 가용성 확보

재고 묶임 손실 해소

주문 발생부터 반품 회수까지(수일간) 묶여 있던 인기·시즌 상품 재고의 정상 판매 기회비용을 완전히 보전합니다.


(3) 악성 주문 통제

구매 프로세스 제어

어드민에서 지정된 악성 고객의 프론트 장바구니/주문서 결제 접근을 사전 제한하여 건전한 전자상거래 질서를 확립합니다.


2. 작업 범위 및 개발 영역

SCOPE


Admin 백오피스

IN SCOPE

회원관리 · 악성고객 설정 & API

• 회원 목록 : 조회조건 및 컬럼에 악성고객여부 추가

• 회원 상세 : 악성고객 지정/해제 토글 스위치 제공

• API 연동 : 프론트 주문 차단용 악성고객 검증 API

• 이력 관리 : 관리자 설정 변경 로그 및 일시 트래킹


Front UI (주문)

IN SCOPE

장바구니 · 주문서 구매 제어 UI

• 장바구니 : [주문하기] 클릭 시 악성고객 차단 모달

• 주문서 : 직접 진입 차단 및 결제하기 버튼 실행 제어

• 안내 UI : 고객센터 문의 유도 및 주문제한 표준 안내

• 예외 가드 : 비로그인 및 일반 고객 프로세스 영향 차단
